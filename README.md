Housing Investment Clustering — National Housing Demand Analysis

I'm using Data from Data.go.th (2024-2025 data) and using Python · Pandas · Scikit-learn · Streamlit · Folium to make this project

by Cleaned and prepared a nationwide housing dataset (feature engineering, normalization) following a structured CRISP-DM workflow
Compared K-Means against hierarchical clustering to find the clearest segmentation of properties by investment potential
Built an interactive Streamlit + Folium dashboard letting users filter clusters by province and property type on a live map
